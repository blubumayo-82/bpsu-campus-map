# Repository Submission Instructions

Submit your group's complete application source code to this GitHub repository.

Before submitting, make sure that:

- The complete source code for your application is included.
- The files are organized clearly and can be identified easily.
- The repository contains the files needed to run the application.
- No passwords, API keys, access tokens, or other sensitive information are committed.

Push your latest changes to this repository before the submission deadline.

**Note:** Upload your PowerPoint presentation separately to Google Classroom, as instructed.
